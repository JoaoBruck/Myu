# Design — Investigation Prototype

## Objetivo
Testar um fluxo em que o Myu deixa de ser apenas uma sequência de páginas e começa a assumir linguagem de jogo de investigação 2D.

## Direção
- clima frio, urbano e silencioso;
- azul acinzentado em vez de preto puro;
- interface funcional, sem caixas genéricas demais;
- informação visual com hierarquia clara;
- evidências como objetos manipuláveis;
- o plano dos personagens não é exposto antecipadamente;
- o jogador/leitor monta relações aos poucos.

## Estrutura
1. **Case Navigation** — categorias da investigação.
2. **Evidence Board** — evidências espalhadas espacialmente.
3. **Evidence Inspector** — leitura detalhada do item selecionado.
4. **Top Bar** — data, capítulo/arquivo e estado da investigação.
