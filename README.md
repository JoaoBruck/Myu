# MYU

Protótipo jogável **MYU — 17:40 v11.2**.

A publicação usa os assets estáveis da v10 com uma camada de código v11.2 para corrigir os problemas de gameplay e aproximar a apresentação do pixel art:

- personagem menor e mais proporcional aos móveis;
- renderização pixelada do sprite e dos cenários em runtime;
- flor da bolsa preservada no atlas original;
- sombra pixelada dinâmica presa aos pés;
- colisão por polígonos + bloqueadores, sem depender das máscaras antigas que deixavam a personagem subir em objetos;
- mesas, balcão, plantas, paredes, placa, postes e corrimãos bloqueados;
- movimento e câmera suavizados;
- cache renovado.
