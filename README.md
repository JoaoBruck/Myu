# MYU

Protótipo integrado entre **Figma + GitHub** para testar o fluxo de desenvolvimento do projeto.

## Protótipo atual
Tela experimental de investigação do Capítulo 3:
- navegação do caso;
- quadro de evidências;
- cartas/documentos investigáveis;
- painel de inspeção;
- estética fria e silenciosa inspirada na identidade "17:40".

## Arquivos
- `index.html` — estrutura da interface
- `styles.css` — identidade visual
- `script.js` — interações simples
- `docs/design.md` — decisões do protótipo

Este repositório começa como laboratório do Myu. Nada deste protótipo deve ser tratado automaticamente como cânone narrativo.
