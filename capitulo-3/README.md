# Capítulo 3 — Vertical Slice Interativo

Este diretório implementa a experiência-base aprovada para o Capítulo 3.

## Princípio
A prosa continua sendo a camada principal. Documentos e investigação aparecem como uma segunda camada, sem substituir a leitura.

## Estados implementados
1. Mirante — abertura "Ela ia voltar".
2. Arquivo de Derick — pedido de transporte e van indisponível.
3. Oficina de Ravi — T-01, T-19 e a ausência do Anexo 4-B.
4. Restaurante — comparação B-12 × T-01 e descoberta do intervalo de 43 minutos.
5. Casa de Gouveia — confronto por evidências, sem escolhas A/B/C; a isca "algodão" força a correção "poliéster".
6. Progresso — localStorage para continuar de onde o leitor parou.

## Escopo desta versão
É um vertical slice funcional da arquitetura do capítulo, não uma substituição silenciosa do texto integral de 68 páginas. O texto integral deve ser incorporado preservando a versão narrativa aprovada, enquanto estes sistemas permanecem como camada interativa.
