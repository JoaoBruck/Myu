# MYU — Outdoor Engine Lab v3

Esta build corrige especificamente os problemas reportados no celular.

- velocidade reduzida para 42;
- movimento determinístico em vez de confiar apenas no solver do Matter;
- protagonista nunca pode sair do polígono caminhável;
- recuperação automática para o spawn se uma posição inválida ocorrer;
- prédio dividido em 5 hitboxes sólidas;
- objetos do cenário continuam sólidos;
- hitbox da protagonista fica apenas nos pés;
- protagonista aumentada para a escala 0.78–0.86;
- debug `?debug=1` mostra polígono, prédio, props e hitbox dos pés.

A cafeteria continua fora do escopo.
